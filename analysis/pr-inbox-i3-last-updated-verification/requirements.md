# I3 PR Inbox 最後更新時間驗證

開發者可在原生 Inbox 掃讀自己的 open PR 時辨識 GitHub 最後更新距今多久。日期缺席或無效時，PR 仍可閱讀與選取。I3 使用獨立 E026、受控回應與既有正式原生列，交付可行性證據。

E025 的程式、情境、入口與證據保留於原歷史實驗。重現採用後的 I2 使用整個 repository 的 `v0.1.107-pr-inbox-native-list-adoption`（`72a6cd3`），初次 I2 使用 `v0.1.103-pr-inbox-i2-verification`（`b14be5f`）。

I3 涵蓋初載、手動刷新、有效及缺失時間、完整結果一次發布、依來源排序、選取與首列回退、空清單、失敗保留舊列和時間、寬窄版及 VoiceOver。正式 App 與資料契約採用、真人 GitHub／OAuth、Draft 徽章、作者、篩選、時間排序及自動刷新另行規劃。
